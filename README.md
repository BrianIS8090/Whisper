# Wisper AI

Wisper AI — приложение для голосовой диктовки и транскрибации аудио на русском языке.

## Основные возможности

- Глобальная диктовка по горячей клавише.
- Транскрибация длинных файлов через Yandex SpeechKit.
- Автоматическая разбивка больших аудио на части с последующей сборкой результата в один Markdown-файл.
- Поле промта для управления стилем текста.
- Вкладка словаря замен: вы задаёте, как слово или фраза должны выглядеть в финальном тексте.
- Явный индикатор процесса распознавания и подробные сообщения об ошибках.
- Сохранение результата транскрибации в Markdown.

## Кому подходит

- Менеджерам и руководителям, которым нужен быстрый текст из речи.
- Командам продаж, производства и проектным отделам для расшифровки обсуждений.
- Всем, кто регулярно работает с большими объёмами аудио.

## Быстрый старт

1. Скачайте `WisperAI_Setup.exe` из последнего релиза.
2. Установите приложение.
3. Откройте Wisper AI и выберите нужный режим: диктовка или транскрибация файла.
